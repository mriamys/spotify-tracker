# Spotify New Track Bot 🎵

Сервис для автоматического отслеживания новых треков и релизов артистов из ваших подписок в Spotify и добавления их в плейлист.

## Как это работает

- **Формирование базы**: при первом запуске фиксируются текущие релизы отслеживаемых артистов, создавая точку отсчёта.
- **Ежедневный мониторинг**: каждый день бот проверяет обновления у всех артистов. При выходе нового сингла или альбома треки сразу добавляются в целевой плейлист.
- **Умная обработка фитов (`appears_on`)**: проверяется реальное участие отслеживаемого артиста в совместном релизе; сборники и сторонние компиляции отфильтровываются.
- **Устойчивость к лимитам (Rate Limits)**:
  - Пакетные запросы к API для экономии квот.
  - Перехват ответов `429 Retry-After` с корректной паузой и сохранением прогресса сканирования.
  - Безопасные интервалы (`SAFE_DELAY`) между запросами.
- **Автообновление сессии**: автоматическое продление токенов доступа Spotipy.

## Стек технологий

- Python 3.11+
- Spotipy
- aiogram
- Docker Compose

## Настройка и запуск

1. Создайте `.env`:
   ```env
   SPOTIPY_CLIENT_ID=ваш_client_id
   SPOTIPY_CLIENT_SECRET=ваш_client_secret
   SPOTIPY_REDIRECT_URI=http://localhost:8888/callback
   PLAYLIST_ID=id_вашего_плейлиста
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```
